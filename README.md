# AIMS Edge ML for Science: Labs and Assignments

New material appears here as the course goes on. **All labs run on Google Colab**, with a GPU, and nothing needs installing on your laptop.

**Opening a lab:** click its *Open in Colab* link below. In Colab, choose *Runtime → Change runtime type → GPU*, then run the first code cell.
It downloads this repository into your Colab session (and pulls the latest version each time). Colab sessions are temporary: save your own work with
*File → Save a copy in Drive*. Set `USE_DRIVE = True` in the first cell to keep the dataset on your Drive between sessions.

|---|---|
| `labNN_*/` | In-class lab notebooks. `*_solution.ipynb` files appear after the session. |
| `A*/` | Assignments. Solutions appear after the due date. |

**Don't edit the notebooks in place.** Copy them first (e.g. `lab01_mine.ipynb`), so `git pull` never conflicts with your work.
