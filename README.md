# AIMS Edge ML for Science: Labs and Assignments

New material appears here as the course goes on. **Everything runs in Google Colab, with a GPU.** You don't need to install anything on your laptop.

## Getting started (first time)
1. Click **Open in Colab** next to the lab in the table below. Sign in with your Google account if asked.
2. **File → Save a copy in Drive.** ⚠️ Do this *first*, or your answers are lost when you close the tab. Your copy opens in a new tab: **work in that one.**
3. **Runtime → Change runtime type → T4 GPU → Save.**
4. Click into the **first code cell** and press **Shift + Enter**. If Colab warns "This notebook was not authored by Google", click **Run anyway**. It downloads the course files (~30 s).
5. Work down the notebook one cell at a time with **Shift + Enter**. The dataset downloads the first time you load it (1–2 min).
6. **Answer questions** by double-clicking the cell that says *Your answers*, typing, then pressing Shift + Enter.
7. Your work saves to Drive automatically (or press **Ctrl/Cmd + S**).

## Coming back later
- Open **your copy** from **Google Drive → Colab Notebooks**, not the link below.
- Colab forgets running results after a break. If you see an error like `name '...' is not defined`, use **Runtime → Run all**. Your written answers stay.
- Optional: set `USE_DRIVE = True` in the first cell to keep the dataset on your Drive, so it doesn't download again each session.

## Handing in an assignment
